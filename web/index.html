On the edge of the screen,
not in a window

It's always there. When a limit is running low, you don't have to remember to check.

An icon you can actually read

Eleven menu bar styles, and the segmented ones can be counted rather than guessed at. The two dual styles put the short and long windows on separate lines, so you see which runs out first.

Alerts in time

A system notification as you near a limit, with warning and critical thresholds you set. It also warns when your pace means it will be tight, or run out before the reset. When a limit resets, the dock slides out and sweeps the ring full, the notch island drops a banner and the menu bar icon refills; if you had run it dry, a notification says you're good to go again.

What you used, what it cost

It reads the CLIs' own session logs: a year-long heat map and tokens by model, with spend estimated on your Mac from public prices and shown in any of 11 currencies. It can turn your week into a share card, too.

Not just the menu bar

Click the menu bar icon for the panel. Tuck it into the notch: one to three providers on each side, opening on hover into limits, usage and overview pages. Stick it to the screen edge: hover for a card, double-click to choose which limit a ring shows. Or put cards on the desktop — big figure, gauge, trend, ranking — in three sizes.

Usage stays on this Mac

Usage is read and worked out on your Mac. No analytics, no tracking. Automatic providers reuse the sign-in your CLI already has; credentials you enter go into the macOS keychain and never into a file.

Everything you'd want to set

Sign-in for each of the 23 providers, icon styles, alert thresholds, desktop cards, usage statistics, service status — all in one window, in English or Chinese. Something to say? Send it from the Feedback page, no sign-in needed.

Questions

What is QuotaBar?
A small app that lives in your Mac's menu bar. It reads the limits, reset times and spend of the AI coding services you use and puts them in the menu bar, the notch, at the screen's edge or on desktop cards, where a glance is enough. It isn't an official app of any provider.
Which providers does it support?
Codex, Claude, Cursor, Gemini, Antigravity, Grok, OpenCode Go, Kimi Code, z.ai, MiniMax, Manus, DeepSeek, Qwen Cloud and GitHub Copilot, plus Alibaba Coding Plan, Volcengine Ark, Zhipu GLM, Moonshot API, OpenRouter, Xiaomi MiMo, Qoder, Windsurf and Kiro — 23 in all. The last 9 are marked experimental while they're verified with real accounts. You turn on only the ones you use.
Do I need API keys?
Mostly not. Codex, Claude, Gemini, Antigravity, Grok, OpenCode Go, Cursor, GitHub Copilot, Windsurf, Kiro and Volcengine Ark reuse the sign-in your CLI or desktop app already has on this Mac — if you're signed in, it can read. The rest need a credential pasted once; Alibaba Coding Plan and Xiaomi MiMo can also sign in inside the app.
Are my credentials safe?
Credentials you enter are stored only in the macOS login keychain, never in the config file. Automatic providers store nothing — each read goes to your CLI's existing session. The app reports no usage to us. Besides each provider's own API, it connects only to the providers' public status pages, open.er-api.com once a day for exchange rates, GitHub for new versions and the model price list, and quota.bar when you send feedback or when GitHub can't be reached for an update. With a proxy set, all of these go through it.
How accurate is the spend?
It's an estimate, not a bill. It scans the CLIs' own session logs and prices them at each provider's published rates. Two easy mistakes are handled: Claude Code writes the same turn into several session files (deduplicated), and Codex's input_tokens already includes the cached part (not billed twice). Prices come from an online catalogue and match model ids exactly. QuotaBar also keeps its own daily archive, so totals don't shrink when a CLI clears old logs.
How do I install it?
Download the .dmg and drag QuotaBar into Applications, or run brew tap gentpan/tap and brew trust gentpan/tap, then brew install --cask quotabar. It's signed with a Developer ID and notarized by Apple, so macOS won't warn about an unidentified developer. The download is served from quota.bar's own server, so it works where GitHub is blocked; the same file is also on GitHub Releases.
What if a provider changes its API?
That provider shows as failed and keeps its last reading with a note that it's out of date — you never get an old figure passed off as a new one. The app can update itself, or use brew upgrade.
Where does service status come from?
Each provider's public status page, read every five minutes, no sign-in. Status is judged by the components used for coding — Claude Code for Claude, the CLI for Codex — and Settings shows each component's current status and the last 30 days. 11 providers have status pages so far; the rest show none.
Can other tools use it?
Yes. Turn on the local API under General in Settings and other tools can read limits from http://127.0.0.1:6736/v1/limits and spend from /v1/spend — on this Mac only, without credentials or account names. QuotaBar --json in a terminal gives the same data.
Which macOS does it need?
macOS 14 or later, on Apple silicon or Intel. The Liquid Glass look needs macOS 26; earlier versions fall back to frosted glass of the same size, with the same layout.
