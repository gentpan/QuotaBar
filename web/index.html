常见问题

QuotaBar 是什么？
一个 macOS 菜单栏应用。它把你在用的 AI 编码服务的额度用量和重置时间读出来，放在菜单栏上。不是任何一家服务商的官方应用。
支持哪些服务商？
Codex、Claude、Cursor、Gemini、Grok、OpenCode Go、Kimi Code、z.ai、MiniMax、Manus、DeepSeek，共十一个。你只启用自己在用的那几个。
需要填 API Key 吗？
大多不用。Codex、Claude、Gemini、Grok、OpenCode Go、Cursor 都是直接复用你本机 CLI 或客户端已经建立的登录会话——你已经登录过了，它就能读。剩下几个需要手动粘一次凭据。
我的凭据安全吗？
手动填写的凭据只存 macOS 登录钥匙串，不会写进配置文件。自动型服务商根本不存——每次直接读你 CLI 已有的会话。整个应用没有任何联网上报：它只和各服务商自己的接口通信。
费用数字准不准？
是**估算**，不是账单。它扫描 CLI 自己的会话日志，按各家公布的标价算。两个容易算错的地方都处理了：Claude Code 会把同一轮对话写进多个会话文件（去重），Codex 的 input_tokens 已经含了缓存部分（不重复计费）。价格从在线目录取，只精确匹配模型 id。
怎么安装？
下载 .dmg 拖进「应用程序」，或者 brew tap gentpan/tap 然后 brew install --cask quotabar。已用 Developer ID 签名并通过 Apple 公证，不会弹「无法验证开发者」。
服务商改了接口怎么办？
那个服务商会显示为失败，并保留上一次的读数配一条过期提示——不会悄悄给你一个旧数字当新的。应用内可以自动更新，也可以走 brew upgrade。
需要什么系统版本？
macOS 14 或更新。Apple Silicon 和 Intel 都可以。液态玻璃效果需要 macOS 26，低版本自动回退到同尺寸的毛玻璃，布局不变。
