贴在屏幕边上，
不占一个窗口

它一直在那儿。额度快见底的时候，你不需要先想起来去查。

一个图标，读得出刻度

十一种菜单栏样式，分段式的格子可以数——不是靠估。双层的两种把短周期和长周期分两行，哪个先见底一眼看到。

到点提醒

接近上限时发系统通知，警告和紧急两档阈值自己定。还会按当前速度提醒「余量很紧」和「重置前会用完」，每条进度条上都标出匀速使用时此刻该在的位置。

用了多少，花了多少

直接读 CLI 自己的会话日志：全年热力图、按模型的 token 数，费用对着公开价目在本地估算，可换算成人民币等 11 种货币。还能生成用量分享卡片。

不止菜单栏

点菜单栏图标打开下拉面板。藏进刘海：两侧各显示一到三个服务商，悬停展开成额度、用量、总览三页。贴在屏幕边缘：悬停看卡片，双击选圆环显示哪个额度。或者在桌面放几张卡片——大数字、仪表、趋势、排行，大中小三种尺寸。

用量不出这台 Mac

用量在本机读取和计算，不做分析，不做追踪。自动型服务商复用你 CLI 已有的登录会话；手动填的凭据进 macOS 钥匙串，不写进任何文件。

该配的都能配

23 个服务商各自的登录方式、图标样式、提醒阈值、桌面卡片、用量统计、服务状态——都在一个窗口里，中英文界面随你选。有话说，反馈页直接发，不用登录。

常见问题

QuotaBar 是什么？
一个常驻 macOS 的小应用。它把你在用的 AI 编码服务的额度用量、重置时间和花费读出来，放在菜单栏、刘海、屏幕边缘或桌面卡片上，抬眼就看见。不是任何一家服务商的官方应用。
支持哪些服务商？
Codex、Claude、Cursor、Gemini、Antigravity、Grok、OpenCode Go、Kimi Code、z.ai、MiniMax、Manus、DeepSeek、Qwen Cloud、GitHub Copilot，以及阿里云百炼、火山方舟、智谱 GLM、Kimi 开放平台、OpenRouter、小米 MiMo、Qoder、Windsurf、Kiro，共 23 个。后面 9 个标为实验性，还在用真实账号验证。你只启用自己在用的那几个。
需要填 API Key 吗？
大多不用。Codex、Claude、Gemini、Antigravity、Grok、OpenCode Go、Cursor、GitHub Copilot、Windsurf、Kiro、火山方舟都是直接复用你本机 CLI 或客户端已经建立的登录会话——你已经登录过了，它就能读。剩下几个需要手动粘一次凭据，阿里云百炼和小米 MiMo 也可以在应用内登录。
我的凭据安全吗？
手动填写的凭据只存 macOS 登录钥匙串，不会写进配置文件。自动型服务商根本不存——每次直接读你 CLI 已有的会话。应用不向我们上报任何用量数据。除各服务商自己的接口外，它只会连接各家的公开状态页、每天取一次汇率的 open.er-api.com、GitHub（新版本和模型价目表），以及你主动提交反馈时的 quota.bar。设置了代理时，这些请求都经过代理。
费用数字准不准？
是估算，不是账单。它扫描 CLI 自己的会话日志，按各家公布的标价算。两个容易算错的地方都处理了：Claude Code 会把同一轮对话写进多个会话文件（去重），Codex 的 input_tokens 已经含了缓存部分（不重复计费）。价格从在线目录取，只精确匹配模型 id。QuotaBar 还会自己按天保存存档，CLI 清理旧日志后统计也不会变少。
怎么安装？
下载 .dmg 拖进「应用程序」，或者 brew tap gentpan/tap、brew trust gentpan/tap，然后 brew install --cask quotabar。已用 Developer ID 签名并通过 Apple 公证，不会弹「无法验证开发者」。
服务商改了接口怎么办？
那个服务商会显示为失败，并保留上一次的读数配一条过期提示——不会悄悄给你一个旧数字当新的。应用内可以自动更新，也可以走 brew upgrade。
服务状态是从哪来的？
各家的公开状态页，每五分钟读一次，不用登录。状态按写代码相关的组件判断，比如 Claude 看 Claude Code，Codex 看 CLI；设置里能看到每个组件的当前状态和最近 30 天。目前 11 家有状态页，没有的就不显示。
能给别的工具用吗？
可以。在设置的「通用」里打开本地接口，其他工具就能从 http://127.0.0.1:6736/v1/limits 读额度、从 /v1/spend 读花费，只对本机开放，不含凭据和账号名。终端里运行 QuotaBar --json 也能拿到同样的数据。
需要什么系统版本？
macOS 14 或更新。Apple Silicon 和 Intel 都可以。液态玻璃效果需要 macOS 26，低版本自动回退到同尺寸的毛玻璃，布局不变。
