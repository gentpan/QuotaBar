新增样式修复删除

  1. 未发布 2026-09-13 开发中

    2026-09-13

    新增
    • 下拉面板服务商卡片的右键菜单新增三组快捷设置：「卡片上显示的额度」逐项勾选哪些额度显示在外面、哪些收进展开箭头（每个服务商分别记住，可恢复默认，最后一项不能取消）；「圆环跟随的额度」选择停靠条圆环、刘海岛和菜单栏跟随的窗口，与双击窗口是同一个设置；「显示位置」勾选这个服务商是否出现在下拉面板、停靠条、刘海岛和桌面卡片，另有「菜单栏只显示此服务商」和「添加一张此服务商的桌面卡片」。原来的「在下拉面板中隐藏」和「圆环改回按最满的窗口显示」并入这几组。
    • 在线更新改为更新卡片：发现新版本时弹出一张卡片，显示新版本号、当前版本、发布日期和这一版的更新内容（按界面语言显示中文或英文，分新增、样式、修复，可展开全部并打开完整更新日志），点「安装并重启」后下载、验证开发者签名和 Apple 公证，完成后自动替换并重启；不会再不打招呼就重启。「更新方式」改为「后台下载」（发现后先在后台下载验证好，点安装即刻完成）和「安装时再下载」。原地替换失败（例如没有「应用程序」文件夹的写入权限）时，卡片说明原因并提供「重试」和「下载安装包」。菜单栏右键菜单、面板顶部横幅和设置里的更新页都打开这张卡片；同一版本每次启动只自动弹出一次。
    • 花费预算提醒：设置 → 提醒新增「花费」卡片，可设每日预算和每月预算（按设置时选的货币，留空即不设），花费用到 80% 和超出时各发一次通知，按天和按自然月分别计算。
    • 每周用量周报：每周一上午 9 点后推送一条通知，写明上周的花费、token 数和用得最多的 CLI 所占比例；上周没有用量时不发。可在设置 → 提醒 →「花费」里关闭。
    • 额度重置日历：设置 → 用量统计顶部新增「接下来 7 天的额度重置」，按天列出已开启服务商的每个额度窗口什么时候重置（今天、明天、具体日期和时间），以及当前剩余或已用，快用完的标成橙色或红色。
    • 停靠条圆环的右键菜单也加上「卡片上显示的额度」「圆环跟随的额度」「显示位置」三组，和下拉面板卡片的右键菜单一致。
    • Quota Run 额度竞速：设置里新增「Quota Run」页。不注册也能用：每次读数自动记进本机成绩账本（保留 60 天），显示进行中的额度窗口和个人最佳（最快用满、用到 50%/90% 的时间、最高峰值），成绩可以复制或保存为分享图片。想上榜时，看过并勾选上传清单后点「用 quota.run 登录」：应用打开浏览器并显示一个验证码，在 quota.run 用 Google、GitHub 或邮箱验证码登录（第一次登录时选用户名），核对验证码后批准连接这台 Mac，应用不经手任何密码或第三方令牌；之后这台 Mac 用存在安全芯片里的签名密钥，作为计分设备把额度读数和每分钟 token 数签名上传到 quota.run，成绩和排名由服务器计算，排行榜在 quota.run，个人主页在 quota.run/@用户名。登录后页面显示 @用户名和登录方式、每台 Mac 的 QuotaBar 版本，可编辑资料和最多 12 个项目，「在 quota.run 管理账号」打开网页账号页；另一台 Mac 用同一个账号登录即可加入，更换计分设备有 7 天冷却；「断开这台 Mac」保留账号和本机记录，「删除账号」删除 quota.run 上的全部数据，两者都要确认。登录邮箱只存在 quota.run 上用于登录，不会显示在主页或榜单上。凭据、令牌、提示词、代码、文件路径和明文邮箱永远不上传；不加入就什么都不上传。关于页的联网清单相应补上 Quota Run。
    • Quota Run 服务商账号绑定：只有能确定来自哪个服务商账号的读数才上传和上榜，应用只上传账号邮箱的单向摘要，邮箱本身不离开这台 Mac；一个 Codex、Claude 等服务商账号只归一个 Quota Run 账号，先上传的先得，登录邮箱与该服务商账号邮箱一致的可以认领，成绩上显示「账号已核实」。设置 → Quota Run 新增「服务商账号」卡片，按服务商列出这台 Mac 登录的账号（邮箱打码显示）和状态：尚未上传、已绑定、账号已核实、被其他 Quota Run 账号占用（附认领方法）；可「解绑」（确认后删除这个账号在 quota.run 上的读数和成绩，并停止从这台 Mac 上传），也可「重新绑定」。个人最佳里没有绑定账号的一轮标为「未绑定服务商账号，不会上榜」。
    样式
    • 设置 → 服务商里展开一行时，「测试连接」和「控制台」不再单独占一行：「控制台」紧跟在服务商名字后面，「测试连接」放在右侧服务状态之前，与名字水平对齐；测试结果仍显示在展开内容下方。需要保存凭据、浏览器登录或授权钥匙串的服务商，这些按钮仍在下方一行。
    • 设置窗口右侧每个分区的标题和说明文字改为同一行显示，按文字基线对齐，不再上下两行；窗口太窄时说明文字先截断，鼠标悬停可看全文。
    • 服务商行标题里的「测试连接」改为小胶囊按钮（带图标，和状态标签差不多高），不再是 30pt 高的大按钮，展开的行不会比收起时高出一截；展开内容里「服务状态」一行的文字与左侧标签对齐，之前比标签高出约 7pt。
    • 服务商卡片默认显示的额度按套餐调整：Codex 只显示套餐本身的额度，有 5 小时限制的套餐显示 5 小时和周窗口，没有 5 小时限制的 Pro 套餐只显示周窗口，GPT-5.3-Codex-Spark 的额度收进展开箭头；Claude 显示 5 小时、周窗口和 Fable 三项。圆环正在跟随的窗口始终显示在外面。其他服务商不变。
    • 下拉面板里拖动服务商卡片时，拖到列表顶部或底部附近会自动滚动，越靠边滚得越快，卡片一直跟着鼠标，服务商很多时也能拖到最上面或最下面。
    修复
    • 切换界面语言后，「圆环跟随的额度」和「卡片上显示的额度」这两项选择会失效：额度窗口的名字随语言变化（「周窗口」和「Weekly window」），选择是按名字记住的。现在切换语言重新读取时，会把选择对应到同一个窗口的新名字上。
    • 本地接口（127.0.0.1:6736）只回应发给 127.0.0.1 或 localhost 的请求，并拒绝来自其他网站的跨站请求，防止网页通过 DNS 重绑定读到用量数字；其他请求返回 403。
    • 在 Codex、Claude 等 CLI 里切换到另一个账号后，下一次读取可能被误认为「额度重置」（新账号用量更低、重置时间不同），弹出重置横幅和通知，趋势图也会把两个账号的数据接成一条线。现在读到的账号和上次不同时，不算重置，这个服务商的趋势重新开始记录。

  3. 0.5.2 2026-09-13 a9168c8
    新增
    • 边缘停靠条在服务商太多、屏幕放不下时可以滚动：条子最高到屏幕上下各留 24pt，其余圆环用滚轮或触控板在条子里滚动。系统滚动条换成内侧一条 2pt 的细线，静止时很淡，滚动时稍亮，停下后淡回去；上下还有更多圆环时，两端渐隐到黑色。滚动时悬停卡片先收起，悬停卡片与圆环的对齐会算上滚动距离；额度重置时，对应的圆环会先自动滚到可见处。

  4. 0.5.1 2026-09-13 b4b64e7
    新增
    • 服务商可以按位置隐藏，而不必停用：下拉面板、停靠条、刘海岛、桌面卡片各自决定显示哪些服务商。隐藏的服务商仍会读取数据、发提醒、计入花费，停用才会停止读取。设置 → 展示方式新增「各处显示的服务商」，每个服务商一行，点位置标签即可显示或隐藏；也可以右键下拉面板里的卡片选「在下拉面板中隐藏」，右键停靠条图标选「在停靠条中隐藏」。
    • 下拉面板底部在有隐藏的服务商时显示「N 个已在面板隐藏」和它们的图标，点「显示」可逐个恢复或打开设置管理；停靠条右键菜单也列出已隐藏的服务商。
    • 应用内更新在连不上 GitHub 时改从 quota.bar 服务器检查和下载，打不开 GitHub 的网络也能收到更新；下载到的安装包照旧要验证开发者签名和 Apple 公证才会安装。关于页「你的数据」里的联网说明相应补上这一项。
    样式
    • 下拉面板页脚的刷新提示：点「全部刷新」或自动刷新完成后的一分钟内显示「刚刚更新」，之后显示「X 分钟后自动刷新」；鼠标悬停显示上次更新和下次自动刷新的具体时间及刷新间隔。以前刷新完立刻显示「5 分钟后刷新」，看起来像按钮没起作用。
    • 节奏提示的文案改为「预计重置时剩 8%」，不再写成含糊的「约 8% 余量」；鼠标悬停时写出算法和用到的数字，例如「这个窗口已过 87%，已用 80%。按这段时间的平均速度，到重置时约用到 92%，剩 8%」。
    • 服务状态的「运行正常」改为「服务正常」；悬停状态点或状态标签时写明来源，例如「来自官方状态页 status.claude.com，按 Claude Code、Claude API 判断，3 分钟前检查」，说明它反映的是服务商官方的服务状态，不是本机登录或额度读数。
    • 边缘停靠条靠近时只展开出图标，不再立刻弹出左侧卡片：等停靠条完全展开后，把鼠标移到某个图标上才显示该服务商的详情卡片；之后在图标之间移动，卡片会直接跟着切换。锁定显示时悬停图标直接显示卡片。
    • 边缘停靠条的展开改为两段：小胶囊先横向拉宽，再纵向拉高，圆环在形状里淡入滑出，不会露在黑色区域外；收起时先缩短高度，再收窄回胶囊。
    • 字标 QuotaBar 的字体从 Sora 换成 Instrument Sans 半粗，设置侧边栏、关于页、下拉面板、刘海岛、分享卡片和复制图片的底栏都跟着换；关于页开源致谢里的字体一并改为 Instrument Sans。
    • 分享用量卡片窗口不再有单独的灰色标题栏：标题栏改为透明，卡片预览和右侧设置一直铺到窗口顶部，和设置窗口一样是一整块；卡片和右侧标题避开左上角的红绿灯按钮并上下对齐。
    修复
    • 英文界面的设置 → 服务商列表里，「Keychain」标签被挤成两行（Keychai / n）：状态标签的位置加宽，文字固定一行。
    • 额度窗口刚开始时节奏估算会乱报（例如 5 小时窗口开始 3 分钟用了 3%，就推算成会用完）：现在至少过了窗口时长的 5%、且不少于 15 分钟，才给出余量、会用完和用完时间的判断；已经用完的仍会立即显示。
    • 边缘停靠条悬停展开时会先瞬间离开屏幕边缘、露出一条缝隙：窗口不再在展开和收起时改变尺寸，只让黑色形状在窗口里生长，全程贴着屏幕边缘；没画出来的透明区域让鼠标直接穿透。
  5. 0.5.0 2026-09-13 0aa04d7

    2026-09-13

    新增
    • 下拉面板回归：左键点菜单栏图标打开，右键仍是刷新、设置、退出。面板顶部是花费卡片，下面每个服务商一张卡片，底部显示版本、下次刷新倒计时、设置和选项菜单。按 Esc 关闭，⌘R 刷新，⌘, 打开设置。
    • 花费卡片：可切换花费、Token、每百万 token 花费三种口径，以及今日、昨日、近 30 天。环形图按来源分色，中间数字滚动变化，悬停来源查看按模型的明细。
    • 服务商卡片默认只显示最重要的两个额度窗口，其余窗口、限额重置次数、30 天用量趋势、今日昨日 30 天花费、状态页和控制台链接收在展开箭头里，展开状态会被记住。
    • 进度条加入节奏判断：细竖线标出匀速使用时此刻应在的位置。预计余量很紧时显示约多少余量，预计重置前用完时显示火苗和用完时间，已经用完显示已到上限。悬停进度条查看按当前速度重置时的用量。
    • 点击百分比在已用和剩余之间切换，点击重置时间在倒计时和具体时刻之间切换，所有界面同步生效。
    • 右键服务商卡片或花费卡片可复制为图片，按 4 倍分辨率放进剪贴板，并弹出已复制提示。
    • 周用量分享卡：按 API 价值或 token 数展示最近 7 天、30 天、3 个月、今年或全部时间，金额满 1000 美元变黑卡，满 1 万美元变蓝卡。可选 4:5、1:1、9:16 比例和署名，支持系统分享、保存 1080 像素 PNG、复制图片和文案。
    • 用量存档：QuotaBar 自己保存每天每个模型的 token 与花费，Claude Code 清理旧日志后统计也不会变少。
    • 启动时先显示上次保存的读数，再在后台刷新。
    • 首次安装时自动检测本机已登录的工具，只开启对应服务商，并显示一张可关闭的欢迎卡片。
    • 共享屏幕或录屏时可隐藏用量：菜单栏只显示 logo，停靠条、刘海岛和桌面卡片暂时隐藏。
    • 三种节奏通知：快用完、余量很紧、重置前会用完，同一周期只提醒一次。
    • 花费可显示为人民币、港币、日元、欧元等货币，汇率每天更新一次。
    • token 统计口径可选包含缓存或仅输入和输出。
    • 服务商请求可走 HTTP 或 SOCKS5 代理。
    • 刘海岛光晕：黑色轮廓外一圈钴蓝柔光，接近告警线时渐变成琥珀色或红色，一道光沿轮廓环绕。可开启低功耗模式，只在刷新、悬停或告警时发光；刘海岛被全屏应用遮住时自动暂停动画。光晕区域不挡住鼠标点击。
    • 刘海岛越线自动弹出：额度第一次超过告警线时，刘海岛自动展开约 4 秒再收回。
    • 刘海岛面板分为额度、用量、总览三页，双指左右滑动或点底部圆点翻页。总览页显示今日和近 30 天花费、各来源占比，并可打开分享卡片。
    • 刘海岛额度图表有条形、圆环、阶梯、数字、趋势线五种样式，点底部标签或在面板上按住 ⌘ 点击切换。
    • 同步状态点改为缓慢呼吸，每次拿到新数据时轻跳一下。
    • 桌面卡片：详细模式的进度条加上节奏刻度和重置倒计时，底部显示今日和近 30 天花费；标准模式在圆环下显示重置倒计时；可按紧迫度排序。
    • 全局快捷键：在设置里录制一个组合键，在任何地方打开下拉面板。
    • 本地接口：开启后本机其他工具可以从 http://127.0.0.1:6736/v1/limits 读取额度，不含凭据和账号；终端运行 QuotaBar --json 输出同样的数据。
