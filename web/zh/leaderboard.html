上榜只要三步

  1. 在 Mac 上装好 QuotaBar。
  2. 打开「设置」→「Quota Run」。个人纪录马上开始记，不用注册。
  3. 想上榜再加入：起个用户名，看清楚会上传什么，点同意。

两种级别

已验证读数从 50% 以内一路平稳上升，没有超过 20 分钟的空档，本地日志里确实有 token 在消耗。

标准读数可信，但少了其中一项——比如窗口过半才加入，或者中途合盖睡了一觉。

怎么算的，怎么防作弊

QuotaBar 里看额度，Quota Run 上比速度。一句话：你不点头，什么都不出 Mac；谁也没法自己报成绩。

本地优先

个人纪录不用注册。最快用满、用到 50% 和 90% 的时间、最高峰值，QuotaBar 都记在你自己的 Mac 上，加不加入都一样。

先说清楚，再上传

不加入就不上传。加入时先把会传出去的内容一条条列给你看，同意了才开始。退出 Quota Run，服务器上和你有关的数据全部删除。

只传读数，不传成绩

应用只上传原始读数，每一轮的成绩和名次都由服务器自己算。客户端声称「两小时用满」，服务器根本不看。

加入后会上传

  • 服务商和套餐名
  • 每个额度窗口的已用百分比、重置时间、读取时间
  • 窗口的长度和范围
  • 服务商账号的单向摘要，不是邮箱本身
  • 本地 CLI 日志里每分钟的 token 数，只有数字

绝不上传

  • 凭据、令牌、Cookie、API Key
  • 提示词、代码、模型的输出
  • 文件和项目路径
  • 明文的账号邮箱

只认一台 Mac

每台 Mac 用一把不出本机的密钥给读数签名，一个账号只计其中一台的读数。换一台计分的 Mac 要等 7 天；同一个服务商账号只能归一个人。

先核对，再分级

读数得平稳、合理地往上走。有空档或者开始得晚的算「标准」；读数往回掉、突然猛跳，或者同一个账号出现在两个人名下，先扣下来复核，不上榜也不上主页。

没有奖品

不发钱，不发奖。桌面客户端做不到无法作弊，只能让作弊又费劲又显眼。能赢的只有面子，和一个展示你做了什么的主页。
