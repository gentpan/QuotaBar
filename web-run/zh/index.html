谁先把额度用满？

Quota Run 是 QuotaBar 的自愿排行榜：看真在写代码的人，多快用完 Codex 的一周、Claude 的五小时、Cursor 的一个月。本周的榜单还空着，谁先跑完一个窗口，谁就是第一。

  1. 1

    装上 QuotaBar

    免费的菜单栏应用，Mac 上所有 AI 编码额度一眼看全。

  2. 2

    先记自己的纪录

    打开「设置」→「Quota Run」。个人最好成绩马上开始记，只存在你的 Mac 上，不用注册。

  3. 3

    加入排行榜

    用 quota.run 账号登录，看清楚会上传什么，点同意。下一个用满的窗口就会上榜。

0.5.3 · macOS 14+ · 免费开源

  • 只传读数，不传成绩

    应用只上传原始读数，成绩和名次都由服务器算。

  • 绝不上传

    凭据、提示词、代码、文件路径，以及明文的账号邮箱。

  • 没有奖品

    不发钱，不发奖。能赢的只有面子，和一个展示作品的主页。
