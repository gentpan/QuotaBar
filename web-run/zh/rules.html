Quota Run 怎么玩

Quota Run 比的是谁更快用完一个订阅的额度窗口：Codex 的一周、Claude 的五小时、Cursor 的一个月。要自己主动加入，读数来自你 Mac 上的 QuotaBar，每一个成绩都由服务器根据签过名的读数算出来。没有奖品。

怎么加入

不注册也有个人纪录：每一轮、最快用满的时间、到 50% 和 90% 的时间、最高峰值，QuotaBar 都记在你自己的 Mac 上，这些不上传。

  1. 打开 QuotaBar 的「设置」→「Quota Run」，点「用 quota.run 登录」。
  2. 看完同意说明。上面逐条列出会上传的内容，你点同意之前，什么都不会离开这台 Mac。
  3. 浏览器会打开 quota.run。用 GitHub、Google 或邮箱验证码登录（不用密码），核对连接码和 QuotaBar 里显示的一致，然后批准这台 Mac。

之后 QuotaBar 每次刷新完都会上传新的读数。退出只要在应用里或账号页上点一下，服务器上和你有关的数据会全部删除。

哪些数据会离开 Mac

应用只上传读数，不上传成绩。客户端声称「两小时用满」没有任何意义，因为每一轮成绩都由服务器自己算。

加入后会上传

  • 服务商和套餐名
  • 每个额度窗口的已用百分比、重置时间和读取时间
  • 窗口的长度和范围
  • 服务商账号的单向摘要，不是邮箱本身
  • 本地 CLI 日志里每分钟的 token 数，只有数字

绝不上传

  • 凭据、令牌、Cookie 和 API Key
  • 提示词、代码和模型的输出
  • 文件和项目路径
  • 明文的服务商账号邮箱

服务商账号：绑定和归属

QuotaBar 会读出每个服务商当前登录的是哪个账号，只上传它的摘要；quota.run 再把摘要加密存一遍。邮箱不会离开你的 Mac，服务器上也还原不出来。

绑定了才能上榜
不带服务商账号的读数不计成绩：一轮里每条读数都带着账号，才有资格上榜。
第一次上传就绑定
一个服务商账号只归一个 Quota 账号，也就是最先用它上传读数的那个人。别人的 Quota 账号里再出现同一个服务商账号，那些成绩会被扣下，不上榜。
用邮箱认领
如果这个服务商账号的邮箱，正好是你在 quota.run 上验证过的登录邮箱，它就归你，哪怕别人先上传过。服务器不需要你额外上传任何东西就能核对；在「账号」→「登录方式」里绑定那个邮箱即可认领。这样认领的账号不会再被别人抢走。
账号已核实
一轮里所有读数都来自用邮箱认领的服务商账号时，名字旁会显示这个标记。它只是标记，不是级别：邮箱不一样的账号照样上榜。
解除绑定
在账号页解除绑定，会删掉你来自这个服务商账号的读数和成绩。仍登录着它的 Mac 下次上传时会重新绑定，除非你在 QuotaBar 里也解除。

成绩级别

每一轮在读数到达时都会核对一遍。榜单上有两种级别，打开「只看已验证」就只剩第一种。

已验证

  • 每条读数都来自归你所有的服务商账号
  • 读数往回掉不超过 2 个点
  • 5 分钟内不会猛涨超过 60 个点
  • 第一条读数不超过 50%，到用满为止没有超过 20 分钟的空档
  • Codex 和 Claude 的轮次里，本地日志确实有 token 在消耗

标准

读数可信，但少了覆盖或活跃那一项——比如窗口过半才加入，或者 Mac 中途睡了一阵。

待复核

读数往回掉、突然猛涨，或者服务商账号归另一个 Quota 账号。先扣下来复核，不出现在榜单和个人主页上。

不计名次

有读数没带服务商账号的轮次。会保存，但不会出现在榜单、最好成绩和最近几轮里。

赛季和榜单

一轮
一个服务商账号、一个额度窗口的一个重置周期：从窗口开始到重置为止。窗口长度在 1 小时到 32 天之间的才参与排名。
一张榜
同一个服务商、同一个套餐、同一种窗口的人比，比如 Codex Pro 20x 的周额度。每个人只出现一次，取最好的一轮。
赛季
赛季就是按 UTC 算的 ISO 周，看的是窗口从哪一周开始，写作 2026-W37。「本周」是当前这一周，「上周」是前一周，「全部赛季」取每个人历来最好的一轮。
比什么
从窗口开始，到第一条达到 100%（99.5% 及以上）、90%、50% 的读数用了多久，以及最高峰值。峰值相同时，先到的排前面。
没有奖品
不发钱，也不发奖。桌面客户端没法做到无法作弊，只能让作弊又费劲又显眼。能赢的只有面子，和一个展示作品的主页。

只认一台 Mac

每台 Mac 用一把不出本机的密钥给读数签名，有安全隔区的 Mac 就存在安全隔区里。一个账号可以连好几台 Mac，但只计「计分 Mac」的读数。把计分换到另一台，要距离上次更换满 7 天；一台都没有时，随时可以选。

隐私

公开的
用户名、显示名称、地区、简介、链接和项目；你的成绩、用时和级别；以及每一轮上榜成绩的用量曲线，也就是百分比在窗口里是怎么涨上去的。
不公开的
登录邮箱只留在 quota.run 用来让你登录，不会出现在主页和榜单上，也不会给任何人看。服务商账号的邮箱压根不会到服务器。
退出
删除账号会从 quota.run 删掉你的主页、项目、读数、成绩、Mac 和登录方式。QuotaBar 停止上传，本地纪录保留。
