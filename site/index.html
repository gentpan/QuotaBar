[[Usage stays on this Mac||用量不出这台 Mac]]

[[Usage is read and worked out on your Mac. No analytics, no tracking. Automatic providers reuse the sign-in your CLI already has; credentials you enter go into the macOS keychain and never into a file. Only if you choose to join the Quota Run leaderboard does one Mac send quota readings — never credentials, prompts or code.||用量在本机读取和计算，不做分析，不做追踪。自动型服务商复用你 CLI 已有的登录会话；手动填的凭据进 macOS 钥匙串，不写进任何文件。只有你主动加入 Quota Run 排行榜，才会从一台 Mac 上传额度读数，凭据、提示词和代码永远不上传。]]

[[Questions||常见问题]]

[[What is QuotaBar?||QuotaBar 是什么？]]
[[A small app that lives in your Mac's menu bar. It reads the limits, reset times and spend of the AI coding services you use and puts them in the menu bar, the notch, at the screen's edge or on desktop cards, where a glance is enough. It isn't an official app of any provider.||一个常驻 macOS 的小应用。它把你在用的 AI 编码服务的额度用量、重置时间和花费读出来，放在菜单栏、刘海、屏幕边缘或桌面卡片上，抬眼就看见。不是任何一家服务商的官方应用。]]
[[Which providers does it support?||支持哪些服务商？]]
[[Codex, Claude, Cursor, Gemini, Antigravity, Grok, OpenCode Go, Kimi Code, z.ai, MiniMax, Manus, DeepSeek, Qwen Cloud and GitHub Copilot, plus Alibaba Coding Plan, Volcengine Ark, Zhipu GLM, Moonshot API, OpenRouter, Xiaomi MiMo, Qoder, Windsurf and Kiro — {{count}} in all. The last 9 are marked experimental while they're verified with real accounts. You turn on only the ones you use.||Codex、Claude、Cursor、Gemini、Antigravity、Grok、OpenCode Go、Kimi Code、z.ai、MiniMax、Manus、DeepSeek、Qwen Cloud、GitHub Copilot，以及阿里云百炼、火山方舟、智谱 GLM、Kimi 开放平台、OpenRouter、小米 MiMo、Qoder、Windsurf、Kiro，共 {{count}} 个。后面 9 个标为实验性，还在用真实账号验证。你只启用自己在用的那几个。]]
[[Do I need API keys?||需要填 API Key 吗？]]
[[Mostly not. Codex, Claude, Gemini, Antigravity, Grok, OpenCode Go, Cursor, GitHub Copilot, Windsurf, Kiro and Volcengine Ark reuse the sign-in your CLI or desktop app already has on this Mac — if you're signed in, it can read. The rest need a credential pasted once; Alibaba Coding Plan and Xiaomi MiMo can also sign in inside the app.||大多不用。Codex、Claude、Gemini、Antigravity、Grok、OpenCode Go、Cursor、GitHub Copilot、Windsurf、Kiro、火山方舟都是直接复用你本机 CLI 或客户端已经建立的登录会话——你已经登录过了，它就能读。剩下几个需要手动粘一次凭据，阿里云百炼和小米 MiMo 也可以在应用内登录。]]
[[Are my credentials safe?||我的凭据安全吗？]]
[[Credentials you enter are stored only in the macOS login keychain, never in the config file. Automatic providers store nothing — each read goes to your CLI's existing session. The app reports no usage to us. Besides each provider's own API, it connects only to the providers' public status pages, open.er-api.com once a day for exchange rates, GitHub for new versions and the model price list, and quota.bar when you send feedback or when GitHub can't be reached for an update. With a proxy set, all of these go through it. Joining Quota Run is optional; after you join, one Mac also sends quota readings and per-minute token counts to quota.run — see quota.run for exactly what is and never is sent.||手动填写的凭据只存 macOS 登录钥匙串，不会写进配置文件。自动型服务商根本不存——每次直接读你 CLI 已有的会话。应用不向我们上报任何用量数据。除各服务商自己的接口外，它只会连接各家的公开状态页、每天取一次汇率的 open.er-api.com、GitHub（新版本和模型价目表），以及你主动提交反馈、或连不上 GitHub 检查更新时的 quota.bar。设置了代理时，这些请求都经过代理。Quota Run 排行榜是自愿加入的；加入后，一台 Mac 还会把额度读数和每分钟的 token 数上传到 quota.run，具体上传什么、绝不上传什么，quota.run 上写得很清楚。]]
[[How accurate is the spend?||费用数字准不准？]]
[[It's an estimate, not a bill. It scans the CLIs' own session logs and prices them at each provider's published rates. Two easy mistakes are handled: Claude Code writes the same turn into several session files (deduplicated), and Codex's input_tokens already includes the cached part (not billed twice). Prices come from an online catalogue and match model ids exactly. QuotaBar also keeps its own daily archive, so totals don't shrink when a CLI clears old logs.||是估算，不是账单。它扫描 CLI 自己的会话日志，按各家公布的标价算。两个容易算错的地方都处理了：Claude Code 会把同一轮对话写进多个会话文件（去重），Codex 的 input_tokens 已经含了缓存部分（不重复计费）。价格从在线目录取，只精确匹配模型 id。QuotaBar 还会自己按天保存存档，CLI 清理旧日志后统计也不会变少。]]
[[How do I install it?||怎么安装？]]
[[Download the .dmg and drag QuotaBar into Applications, or run brew tap gentpan/tap and brew trust gentpan/tap, then brew install --cask quotabar. It's signed with a Developer ID and notarized by Apple, so macOS won't warn about an unidentified developer. The download is served from quota.bar's own server, so it works where GitHub is blocked; the same file is also on GitHub Releases.||下载 .dmg 拖进「应用程序」，或者 brew tap gentpan/tap、brew trust gentpan/tap，然后 brew install --cask quotabar。已用 Developer ID 签名并通过 Apple 公证，不会弹「无法验证开发者」。安装包放在 quota.bar 自己的服务器上，打不开 GitHub 也能下载；同一个文件也可以从 GitHub Releases 下载。]]
[[What if a provider changes its API?||服务商改了接口怎么办？]]
[[That provider shows as failed and keeps its last reading with a note that it's out of date — you never get an old figure passed off as a new one. The app can update itself, or use brew upgrade.||那个服务商会显示为失败，并保留上一次的读数配一条过期提示——不会悄悄给你一个旧数字当新的。应用内可以自动更新，也可以走 brew upgrade。]]
[[Where does service status come from?||服务状态是从哪来的？]]
[[Each provider's public status page, read every five minutes, no sign-in. Status is judged by the components used for coding — Claude Code for Claude, the CLI for Codex — and Settings shows each component's current status and the last 30 days. 11 providers have status pages so far; the rest show none.||各家的公开状态页，每五分钟读一次，不用登录。状态按写代码相关的组件判断，比如 Claude 看 Claude Code，Codex 看 CLI；设置里能看到每个组件的当前状态和最近 30 天。目前 11 家有状态页，没有的就不显示。]]
[[Can other tools use it?||能给别的工具用吗？]]
[[Yes. Turn on the local API under General in Settings and other tools can read limits from http://127.0.0.1:6736/v1/limits and spend from /v1/spend — on this Mac only, without credentials or account names. QuotaBar --json in a terminal gives the same data.||可以。在设置的「通用」里打开本地接口，其他工具就能从 http://127.0.0.1:6736/v1/limits 读额度、从 /v1/spend 读花费，只对本机开放，不含凭据和账号名。终端里运行 QuotaBar --json 也能拿到同样的数据。]]
[[Which macOS does it need?||需要什么系统版本？]]
[[macOS 14 or later, on Apple silicon or Intel. The Liquid Glass look needs macOS 26; earlier versions fall back to frosted glass of the same size, with the same layout.||macOS 14 或更新。Apple Silicon 和 Intel 都可以。液态玻璃效果需要 macOS 26，低版本自动回退到同尺寸的毛玻璃，布局不变。]]
